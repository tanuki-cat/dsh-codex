# 0.3.13 发布说明

## 概要

正式版 `0.3.13` 新增 `/init`、默认折叠的初始化任务通知，以及随包分发的 Codex 模型目录请求版本配置。发布渠道为 GitHub Release，不发布 npm；本次不自动安装或重启现有 DSH。

## 目录

- [发布内容](#发布内容)
- [安装与升级](#安装与升级)
- [验证与限制](#验证与限制)

## 发布内容

- `/init` 由当前会话 Agent 在独立回合生成当前会话文件系统目录的 AGENTS.md。已有文件、存在性不确定或创建冲突时停止，不覆盖；参数、附件、取消和准备期间卸载有专门处理。
- 完整指令标记为 `codex-init` 来源，复用宿主原生默认折叠的任务触发通知；展开可查看原文，不伪装成模型思考。模型输入与日志保留原文，普通用户消息、工具执行及旧历史不变。
- [独立版本配置](<../config/codex.json>)默认 `0.162.1`，只控制远端模型目录的 client_version，不安装或升级 CLI。配置有效时保持环境变量 → 本机 CLI → 内置配置的选择顺序。
- 配置缺失或非法只拒绝远端模型目录检查与应用；登录、usage、图片、初始化及原生目录恢复不因此禁用。修复配置后重启 DSH。

## 安装与升级

从 [v0.3.13 GitHub Release](<https://github.com/tanuki-cat/dsh-codex/releases/tag/v0.3.13>) 下载安装包，在下载目录执行：

```sh
dsh plugin --profile web add ./dsh-llm-chatgpt-0.3.13.tgz
```

安装前备份 profile 配置；安装后重启承载插件的原 DSH Web 进程并刷新页面。只刷新浏览器不会更新服务端插件或版本配置。既有旧历史长气泡不迁移；在新执行的 `/init` 中验收折叠通知。

本机自动化宿主版本为 `0.2.1-alpha.1`。初始化要求 commands 与 followup 能力；折叠展示取决于宿主客户端能力，通知标题由宿主提供。规则加载取决于启用的 agent-instructions 组件。
