# Codex usage 命令与剩余额度显示

## 状态与概要

状态：已实施并通过自动化验证（2026-10-09）。基于 0.3.10 源码，尚未发布或部署；旧版额度条方案和发布记录保持冻结。

在对话框提交 `/usage`，由宿主命令服务直接查询账号共享的 5 小时和周额度，不调用模型。自动额度条显示剩余可用，并将正常轮询从一分钟改为五分钟。

- 复用[额度服务](<../src/usage.ts>)固定的 `https://chatgpt.com/backend-api/wham/usage` 端点和 DSH 凭据，不新增 OAuth 或模型协议。
- 现有解析器仅保留 18000 秒窗口；测试含 604800 秒周窗口样例，真实账号字段和权限仍需实测。
- 现有成功缓存、前端最小间隔和旧数据标记为 60 秒，展示有效期五分钟。
- 已安装宿主提供 `commands.register({ name, description, handler })`；handler 接收 `rawInput` 和 `signal`，返回 `{ kind, text }`。命令发现和对话结果渲染由宿主负责。
- 当前目录未在 IDEA 打开；使用项目 TypeScript、tsdown 和 Node 测试，不以无关 IDE 项目代替。

## 用户行为

### /usage

无参数命令，额外参数返回用法错误且不发起查询。输出参考 Codex status 的额度区：

```text
Codex usage

5 小时额度 [████████░░] 88% 剩余可用 · 12% 已用
           重置：2026/10/09 19:35
周额度     [██████░░░░] 58% 剩余可用 · 42% 已用
           重置：2026/10/14 01:50

查询时间：2026/10/09 15:40
```

示例只说明格式，不代表真实账号数据。百分比保留最多一位小数；日期包含年月日，并注明宿主本地时区。额度条使用浏览器本地时区。不输出账号 ID、邮箱或令牌；不猜测套餐、token 数或剩余请求次数。

缺失窗口显示“未返回额度”，无效或已重置窗口单独说明，不显示虚假的 0% 使用。无 reset 显示重置时间未知。缓存结果标注缓存及查询时间；失败时保留仍有效的窗口并标旧，显示固定失败文案。账号受限时说明剩余不保证可调用。

### 自动额度条

- 保持现有普通本机 Codex 会话条件、槽位和交互，不新增浮层或样式体系。
- 主文案、填充比例、按钮无障碍名称和独立 progressbar 全部表示剩余可用。
- 剩余 ≤20% 警告，≤5% 危险，复用原主题颜色。未知额度不带数字进度语义。
- 悬浮详情优先剩余，再列已用、重置、查询时间和限制状态。
- 点击条仍遵守自动缓存期限；主动检查使用 `/usage`。

## 数据与时效

浏览器安全的共享策略模块统一前后端规则：

| 策略 | 值 | 约束 |
| --- | --- | --- |
| 正常自动查询 | 5 分钟 | 首次订阅立即查询；成功缓存五分钟 |
| 主动查询最小间隔 | 1 分钟 | 距最近实际查询不足一分钟返回缓存 |
| 旧数据标记 | 5 分钟 | 正常等待周期内不标旧 |
| 最大展示年龄 | 15 分钟 | 暂时失败可保留同账号旧数据，到期清除 |
| 失败退避 | 1、2、4、5 分钟 | 人工查询不能绕过 |
| Retry-After | 上游优先 | 所有查询不能提前出站 |

双窗口按 `limit_window_seconds` 识别，不固定 primary/secondary 顺序。5 小时为 18000 秒，周为 604800 秒；只使用账号级 `rate_limit`，不混入模型专属限制。数据保存 `fiveHour`、`weekly`、各窗口不可用原因、共同查询时间和账号 allowed 标志。

窗口独立降级：已识别窗口缺失、重复、百分比无效或 reset 已过，不阻断另一合法窗口。无法识别时长的畸形结构和账号不匹配为整体失败。百分比限定 0–100，秒级 reset 转毫秒并校验安全范围。到达 reset 立即清除对应旧值，不清除仍有效的另一个窗口。成功缓存期限取五分钟和有效窗口最早 reset 的较小值；主动频率与失败退避仍为出站下限。

## 服务与生命周期

- 每个插件实例只创建一个额度服务，父作用域 effect 销毁。Web 与可选 commands 注入复用实例。Web 子作用域卸载只销毁路由和管理器，不关闭命令服务使用的缓存。
- commands 可选注入；无该服务的旧宿主仍可登录和查看额度条。使用现有最小结构接口惯例，不安装依赖或静态引入可选包。
- 主动和自动查询共用 single-flight，保留身份 fingerprint、账号变化清缓存及登录暂停。
- 命令取消只停止调用者等待，不取消其他页面共用查询；不展示取消后的晚到结果，清理监听器。
- 保留上游 10 秒超时、总预算 25 秒、256 KiB 响应上限、禁止重定向、401/403 清数据和 Web capability/origin 校验。
- 不泄漏 access、refresh、accountId 或上游原始错误。

## 验证与验收

- 服务：双窗口交换、0/100/小数、缺失/重复/无效窗口、独立 reset、安全字段、五分钟缓存、一分钟主动查询、并发合并、退避不可绕过、账号切换和销毁。
- 前端：五分钟之前不查且不标旧；隐藏/离线暂停；请求未完成也到期清值；恢复只发一个请求；剩余填充、20%/5% 阈值、无障碍数值和未知无进度条。
- 命令：无参数发现执行、双窗口文本和时区、缓存/旧数据、错误不泄密、部分窗口到期、取消不破坏共享请求；真实宿主命令不调用模型。
- 使用假时钟、注入 fetch 和 deferred barriers，不等待真实五分钟或依赖外网。
- 计划执行 `npm run check`、`npm run build`、Node 聚焦测试、带 `DSH_INSTALL_ROOT` 的宿主相关集成及 `git diff --check`；实施记录只列实际执行结果。
- 不自动部署 GUI；真实账号和两种主题浏览器验收若未执行，明确注明，不以历史截图代替。

## 风险与实施记录

- usage 不是稳定公开 API；字段变化降级额度查询，但不能阻断发送消息。
- 五分钟周期有显示延迟；明确更新时间，主动命令允许一分钟后检查。
- 宿主时区与远程浏览器可能不同；命令明确时区，前端沿用浏览器时区。
- 命令结果经宿主对话日志持久化，仅含额度与时间，无账号身份信息。
- HTTP DTO 与客户端同步升级；部署需重新加载页面，不保证旧客户端热混用。

- [额度服务](<../src/usage.ts>)解析 5 小时及周窗口，各自缺失、无效或 reset 到期时独立降级。共享策略统一五分钟刷新和十五分钟展示有效期。
