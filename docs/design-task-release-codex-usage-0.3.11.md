# Codex usage 命令与额度卡片：0.3.11 发布说明

## 概要

`dsh-llm-chatgpt 0.3.11` 提供 `/usage` 双窗口额度查询，显示账号共享的 5 小时与周剩余额度，并将输入栏额度条统一为剩余可用。功能源码与用户已安装验收的 `0.3.11-dev.2` 相同；正式版本仅调整版本和发布材料。

发布渠道沿用 [GitHub Release v0.3.11](<https://github.com/tanuki-cat/dsh-codex/releases/tag/v0.3.11>)，不发布 npm。远端发布状态以该 Release 为准。

## 新增与行为

- 在对话框提交无参数 `/usage`，由宿主命令服务查询，不调用模型。5 小时与周窗口独立处理缺失、无效和重置，不根据会话 token 推算额度。
- 支持专用命令槽位的宿主默认展开双窗口卡片，宽屏并排、窄屏上下排列；折叠摘要仅保留两项额度。旧文本历史可转换为卡片，错误及未知格式保留文本。
- 卡片与输入栏的进度条统一表示剩余：正常绿色，剩余 ≤20% 橙色、≤5% 红色；数值和无障碍语义同步，未知窗口不伪装成 0%。
- 正常自动轮询由一分钟改为五分钟；主动命令最短间隔一分钟。共享缓存、并发请求和账号隔离，人工查询不能绕过失败退避或 Retry-After。
- 查询时间、完整重置日期及缓存/失败提示仍保留。暂时失败仅保留十五分钟内且尚未重置的同账号旧窗口；取消命令只释放当前等待者。
- 复用 DSH OAuth 凭据，结果不包含 token、邮箱或账号 ID；Web 管理接口仍校验 capability 和 Host/Origin。

## 安装和升级

从 Release 下载 [安装包](<https://github.com/tanuki-cat/dsh-codex/releases/download/v0.3.11/dsh-llm-chatgpt-0.3.11.tgz>)，在下载目录执行：

```sh
dsh plugin --profile web add ./dsh-llm-chatgpt-0.3.11.tgz
```

安装会修改本机 `web` profile，请先备份。重启对应 DSH Web 进程并重新加载页面，加载新的命令与卡片；仅刷新页面不能更新服务端插件。升级自开发版也需安装正式包。宿主条件见[使用指南](<../README.md#前置条件>)。

## 验证边界

- 功能源码已执行类型检查、构建与 138 项测试，0 失败、0 跳过。组件替身验证双窗口文本解析、独立数字进度、色阶阈值、折叠和未知数据降级。
- 已安装宿主的真实 Host SlotCore 验证 keyed 命令与 list 额度条的注册/共存；真实 CommandRuntime 验证命令发现、执行、生命周期日志、缓存共享及卸载。网络、凭据和会话日志容器使用替身，不向模型发送命令。
- 用户在 2026-10-09 反馈 `0.3.11-dev.2` 安装测试“验证通过”。未提供验收项明细；此结论不等同于逐项深浅色、移动宽度、VoiceOver 或跨平台验证。
- Agent 的 Firefox 无头预览未能识别隔离 profile 目录，因此没有完成新的浏览器截图或逐主题视觉验收。旧版截图不作为本版本验收证据。

## 发布检查

正式包需要通过以下项目自有检查，不安装到真实 profile、不重新登录或改写凭据：

```sh
npm pack --cache .npm-cache
git diff --check
```

`prepack` 已通过类型检查和构建。正式包解包 smoke 已确认版本 `0.3.11`、server/client 入口、专用 `/usage` 槽位、色阶阈值与未登录的安全错误输出。18 个 `lib` 产物与已验收 `0.3.11-dev.2` 安装包逐字节一致，沿用此前 138 项功能回归，不因提交或 push 单独重复。发布记录落盘后仅用 `npm pack --ignore-scripts --cache .npm-cache` 更新文档内容；功能构建不变。

## 限制

- usage 是私有后端 API；字段或账号权限变化时查询降级，不承诺长期兼容或剩余请求次数。剩余额度不保证模型权限及其他限制允许调用。
- 命令日期使用并标注宿主本地时区，输入栏详情使用浏览器时区，远程浏览器与宿主可能不同。
- 旧宿主没有 commands 服务时不注册 `/usage`；没有专用命令槽位时使用原文本。既有设置页登录仍保留。
- 输入栏额度条仍限于可确认的普通 loopback Codex 会话；不新增远端 subagent 额度显示。

当前行为以[使用指南](<../README.md>)和源码为准；初版查询设计与历史验证见[实施记录](<design-task-feature-codex-usage-command.md>)。
